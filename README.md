# Azure Infrastructure Lab

A hands-on Azure infrastructure lab built to develop practical skills across compute, networking, identity, storage, and governance — aligned to the AZ-104 Microsoft Azure Administrator exam objectives. Built to demonstrate real-world infrastructure engineering capability in hybrid cloud environments relevant to enterprise and UK government deployments.

---

## Lab Objectives

- Deploy and manage Azure compute resources including containers and virtual machines
- Design and implement virtual network architecture with proper segmentation and security controls
- Configure identity and access management using Entra ID and RBAC
- Implement storage solutions and governance controls using Azure Policy
- Monitor infrastructure using Azure Monitor and Log Analytics
- Automate infrastructure deployment using Terraform (Infrastructure as Code)
- Integrate Active Directory with Entra ID in a hybrid identity model
